# File Analyzer

Веб-сервис на **FastAPI** для анализа успеваемости студентов из Excel-файлов. Загружаете таблицу с оценками — сервис группирует данные, считает средний балл, находит лучшую группу, строит сводную диаграмму по оценкам и выгружает список должников. Проект находится в активной разработке, функциональность будет пополняться.

🔗 Репозиторий: https://github.com/kopar89/File_Analyzer
🐳 Docker-образ: [koparr/file-analyzer:v1.1.2](https://hub.docker.com/layers/koparr/file-analyzer/v1.1.2)

## Возможности

- Загрузка Excel-файла (`.xlsx` / `.xls`) со списком студентов
- Группировка отличников (оценка «5») по группам с разбивкой по листам Excel
- Расчёт среднего балла по каждой группе
- Определение группы с лучшим средним баллом
- Подсчёт количества оценок по группам + сводный лист с круговой диаграммой распределения оценок
- Выгрузка списка студентов-должников (оценка «2»)
- Простой веб-интерфейс (статические HTML-страницы)

## Требования к файлу

Загружаемый Excel-файл должен содержать столбцы:

| Группа | ФИО | Оценка | Предмет |
|--------|-----|--------|---------|

## Запуск через Docker (рекомендуется)

```bash
docker pull koparr/file-analyzer:v1.1.2
docker run -d -p 8000:8000 --name file-analyzer koparr/file-analyzer:v1.1.2
```

Сервис будет доступен на [http://localhost:8000](http://localhost:8000).

## Запуск локально

```bash
git clone https://github.com/kopar89/File_Analyzer.git
cd File_Analyzer

python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

## Использование

1. Откройте `http://localhost:8000` в браузере.
2. Загрузите Excel-файл со студентами.
3. Перейдите к нужному отчёту через доступные эндпоинты (см. ниже) или интерфейс.

## API-эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `GET`  | `/` | Главная страница |
| `POST` | `/load_xl` | Загрузка Excel-файла со студентами |
| `GET`  | `/show_btn` | Страница с кнопками отчётов |
| `GET`  | `/upload_db` | Дополнительная страница |
| `GET`  | `/group_by` | Список отличников, сгруппированных по группам (файл `grouped_students.xlsx`) |
| `GET`  | `/avg` | Средний балл по каждой группе (`average_students.xlsx`) |
| `GET`  | `/best_group` | Группы, отсортированные по среднему баллу (`best_group.xlsx`) |
| `GET`  | `/group_count` | Количество оценок по группам + диаграмма распределения (`group_count.xlsx`) |
| `GET`  | `/duty_student` | Список студентов с оценкой «2» (`duty_student.xlsx`) |

## Технологический стек

- Python 3.12
